UI Tips

Clicking a slot will remove the green border around it.
The randomizer will no longer generate that slot.

Hovering over a slot will reveal two buttons :
  • Dice button that rerolls that slot only
  • Chain button that goes back in the progression
    chain of that weapon.
Known Issue
  • Firefox won't display some elements correctly
  • Price limit slider only works when pressing
    "Generate Loadout", not when rerolling a slot.
